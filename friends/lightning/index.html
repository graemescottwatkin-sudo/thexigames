How to play

Sixty seconds. Answer as many Friends questions as you can. Each has four answers and one is right.

Right is a point. Wrong costs three seconds off the clock. The answers to the ones you missed are shown when the time is up.

Each day’s run is the same questions for everyone, so scores can be compared. It opens on an easy one and gets harder in places. Your first run of the day is the one that counts.

Practice as often as you like. It avoids questions you have seen lately and today’s run.
